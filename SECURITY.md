# Security Policy

## Reporting a concern

Do not publish credentials, private network details, or sensitive diagnostic output in a public issue. For security-sensitive reports, contact the repository maintainer privately through a channel listed on their GitHub profile.

## Safe use

This repository is intended for local diagnostics. The included script does not change network settings. Review any command before running it, especially commands using `sudo`.

Do not use this guide to bypass university network authentication, device registration, or other access controls.
